# Quantifier Game: demo for RIMS Kôkyûroku (frozen version)

This folder is a static website that runs entirely in the browser. It needs no application server and no external CDN: the game AI, the strategy search, the exact global verification and the proof generation are run in the browser by the TypeScript core. The version and the hashes of the sources are listed in `MANIFEST.json` and at the bottom of the page.

The page opens in English. The switch in the header (English / 日本語) changes the language; the browser remembers the choice. `?lang=en` or `?lang=ja` in the address selects the language directly.

The demo is published at <https://yf-fyf.github.io/2026-rims-quantifier-game/> from the repository [yf-fyf/2026-rims-quantifier-game](https://github.com/yf-fyf/2026-rims-quantifier-game).

## Publishing on GitHub Pages

1. Put all the contents of this folder at the publishing source of the Pages repository (its root or `docs/`), including `.nojekyll`.
2. In the repository's Settings → Pages, choose the branch and folder to publish.
3. Open the published address. All paths are relative, so the site also works under a subpath or at another address.

Choose an example under “Topic and conditions”, choose Affirmative or Negation, and open it. Problems whose coefficients can be changed are under “Advanced: problems with parameters”. Each example can be opened directly with `?example=`; for the negation, add `-dual` to the key.

| Key | Example |
| --- | --- |
| `limit-0` | Does 1/n converge to 0? |
| `limit-1` | Does 1/n converge to 1? |
| `cont-linear` | Is 2x continuous at x=1? |
| `cont-square` | Is x² continuous at x=2? |
| `cont-jump` | Is a function changed only at x=0 continuous at x=0? |
| `bool-same` | Can one return the same truth value as the input? |
| `bool-order` | Can a single value match every input? |
| `bigo-square` | Is 8n²+100n+543 in O(n²)? |
| `bigo-linear` | Is n²+n+1 in O(n)? |

Example: <https://yf-fyf.github.io/2026-rims-quantifier-game/?example=limit-1-dual&lang=en>

The keys of earlier versions, `s01`, `s03`, `s04` and `s05` (and `s03-dual`), still open `limit-0`, `limit-1`, `cont-linear` and `bigo-square`.

## Notes

- At startup the page loads a few hundred KB (the interface and the game engine) and is usable within a few seconds in most environments. The linear-programming solver used for strategy synthesis (HiGHS, about 3.5 MB of WebAssembly) is loaded in the background afterwards.
- Game records are kept only in the browser tab and are lost when the page is reloaded.
- Opening `index.html` directly (`file://`) is not supported. Locally, serve the folder, for example with `python3 -m http.server 8000 --bind 127.0.0.1`.
- The licences of the bundled software are in `THIRD_PARTY_NOTICES.md`.
